section: Security
---

- **The gateway and the node are built with Go 1.27.4.** Go 1.27.1 had 15 standard library
  advisories fixed in 1.27.2 to 1.27.4. The one that reached the gateway's code is
  [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859): a race around `http.MaxBytesReader` could
  crash an HTTP/1 server. Others cover HTTP/2, `crypto/x509`, `crypto/tls` and `html/template`.
  `govulncheck` finds none left. The Go modules are unchanged. (gateway, node)
