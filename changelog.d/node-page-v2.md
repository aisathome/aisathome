- **The "Run a node" page leads with the one-line Linux install.** `/node/` opens with the same
  block as the home page (one component, so the two cannot offer different commands): the
  `curl … | sh` one-liner beside the Windows installer, then a short "What you need" with the full
  table folded, a picture of the node's own page with its v0.7.0 controls, "Link it to an account"
  and "How the node runs" for v0.7.0 (the engine's own user, MTP on 24 GB cards, the permanent
  uninstaller). The stop, start and remove table moved to `/node/operate/` (with Linux and Windows
  columns), the tested systems to `/node/binaries/`, and `/node/update/` says that updating a 24 GB
  node to v0.7.0 turns MTP on and how to keep it off. The node software's structured data is on
  `/node/` now, with its version, release notes and GitHub download. (site)
